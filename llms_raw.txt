# MuleSoft Documentation

> MuleSoft is a unified integration, automation, and API management platform that enables organizations to easily connect any application, data, and device to create seamless digital experiences.
> This file is an index of LLM-friendly documentation guides for all MuleSoft products.
> Use the llms.txt files below for information about specific products. Each file has a corresponding llms-full.txt file that concatenates all content for that product or guide.
